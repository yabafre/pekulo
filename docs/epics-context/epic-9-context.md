## Previous stories — outcomes

### Story 9-2-pwa-offline-cache — done 2026-07-25T20:50:00Z

- **Decisions:** Two layers per ADR-0018 (supersedes ADR-0003): `public/sw.js` runtime-caches the SHELL, an encrypted
  IndexedDB persister holds the DATA — the cap screens read through Server Actions (POST), which the Cache API cannot
  store. Offline identity is resolved from the httpOnly cookie by a `"use server"` action answering THREE states
  (`{userId}` / `null` = signed out / throws = backend unreachable): collapsing the last two lets a Supabase outage
  purge a legitimate snapshot. The persister is keyed on the RESOLVED IDENTITY, never on component mount — `Providers`
  sits in the root layout and never unmounts, so a mount-keyed guard leaks one account's cache into another's.
- **Files:** `apps/web/public/sw.js`; `apps/web/src/lib/offline/{cache-db,cache-crypto,query-persister,use-offline-persistence,routes}.ts`
  - tests + `sw.test.ts`; `apps/web/src/app/(cap)/_actions/offline-actions.ts`;
    `apps/web/src/components/{offline-banner,service-worker-registrar}.tsx` + tests; `providers.tsx`, `app/layout.tsx`,
    `lib/security/headers.ts`, `next.config.ts`, `sign-out-button.tsx`, `messages/{fr,en}.json`; `docs/adr/0018-*.md`.
- **Contracts:** `offline` i18n namespace (`aria`/`title`/`age`/`expired`) in fr + en. `OFFLINE_ROUTES` is declared
  TWICE on purpose (`routes.ts` for the bundle, `sw.js` for the worker); `routes.test.ts` reads sw.js and fails on
  drift. `SHELL_CACHE_PREFIX` in `cache-db.ts` mirrors `VERSION` in sw.js — sign-out drops both stores.
  `OFFLINE_FEATURE_PREFIXES` = dashboard / holdings / realestate; `OFFLINE_MAX_AGE_MS` = 60 min (NFR-20).
- **Visual gate:** A fixed banner that offsets the page MUST also paint the band it opens — `html` and `body` are
  both transparent in this app and the only opaque surface is bento's `.shell`, so padding `body` uncovers the
  browser's white canvas. And the offset must be MEASURED from the element, never a constant: the constant was
  sized against the one-line English copy and the French copy wraps. Both were found only by the live pass.
- **Deviations from plan:** The epic cited "SWR on 3 routes" and a session-derived key — both dead since story 11-7
  made the cookie httpOnly; ADR-0018 records the pivot. The cached `/dashboard` document carries the signed-in email
  in its flight payload (the cap layout passes it to a client component), so sign-out must purge the SW cache as well
  as IndexedDB — not anticipated by ADR-0003. **AC-1's offline reload and AC-5 were never observed end-to-end in a
  browser**: CDP network emulation resets on every navigation, so the driver cannot hold the page offline across a
  reload. Unit tests drive the real `sw.js` for those paths; a manual pass is still owed before public ramp.

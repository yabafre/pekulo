## Architecture references

- Patterns to respect:
  - **Test contract** (architecture.md:631) — "`@pekulo/ui` components: 1 visual snapshot + 1 vitest-axe a11y spec per public component." All 33 primitives are exported through `src/primitives/index.ts`, so the contract covers them, not just the `Pekulo*` domain components. Enforced by `packages/ui/src/ds-coverage.meta.test.ts` enumerating `src/index.ts`.
  - **Test pyramid** (architecture.md:247, ADR-0002) — `@pekulo/ui` + `apps/web` run **vitest**; `apps/api` runs **bun test**; `apps/mobile` runs **jest (`jest-expo`)**. CI fans out through per-package `test` scripts (`bun --filter='*' run test`) — never short-circuit the workflow to a single runner (lesson 2026-05-07).
  - **R11 folder-by-domain** (architecture.md:776) — components follow `components/PekuloX/PekuloX.tsx` + co-located `PekuloX.a11y.test.tsx` / `PekuloX.snapshot.test.tsx` / `index.ts`. **Primitives are flat files in `src/primitives/`.**
  - **Platform-split native surface (`@pekulo/ui` 10-2)** — `packages/ui/package.json` routes React Native consumers via the `"react-native"` export condition to `./src/index.native.ts`. Platform-specific modules use `*.native.{ts,tsx}` (`animations.native.ts`, `fonts.native.ts`, `provider/index.native.tsx`, etc.) resolved by Metro and `apps/mobile/tsconfig.json` (`"customConditions": ["react-native", "react-native-legacy-deep-imports"]`, `"moduleSuffixes": [".native", ".ios", ".android", ""]`), while `packages/ui/tsconfig.json` excludes `**/*.native.{ts,tsx}` for web typecheck.
  - **RSC client/server barrel split** (lesson 2026-05-07) — `packages/ui/src/index.ts` is RSC-safe; raw `tamagui` exports (`View`, `Text`, `styled`) live in `packages/ui/src/client.ts` (`@pekulo/ui/client`). Web snapshot tests and `public/tamagui.generated.css` must stay zero-regression (`tamagui-css-fresh` CI guard).
  - **`@pekulo/ui` is the sole styling surface** (architecture.md:552) — `tailwindcss` outside the package is forbidden, lint-enforced by `pekulo/no-tailwind-outside-ui`.
  - **R7 barrel discipline** (architecture.md:748) — `provider/` must not import from `components/`. Snapshot files import the component directly (`./PekuloX`), never through the package barrel, so they cannot close a cycle.
  - **Snapshots encode Tamagui atomic classes** generated at runtime under `disableInjectCSS`. They are coupled to the Tamagui version, not to the committed `public/tamagui.generated.css` — that artefact has its own CI guard (`tamagui-css-fresh`).

  - **ADR-0002** — Test pyramid (Vitest + Playwright + axe + Lighthouse CI + pytest + Jest/RNTL for `apps/mobile`).

### Story 10-1-visual-snapshot-suite — done 2026-08-25T18:35:00Z

- **Decisions:**
  - The DS coverage gate enumerates **`src/index.ts`**, not a hard-coded folder list. A new `export * from "./x"` fails `ds-coverage.meta.test.ts` until it is covered or given a reason in `MODULE_EXEMPT`. Do not re-narrow it to `components/` + `primitives/` — that hole let `PekuloToastViewport` ship publicly with no test at all.
  - Exemptions are **by documented decision, never by invisibility**. `PekuloRootProvider` is the only entry (`next/script` cannot mount in this harness; `test/setup.tsx:44` hits the same wall). Adding one requires the reason to survive review.
  - Spec titles are load-bearing: `test:visual` / `test:axe` select on `--testNamePattern`, so a `describe` missing its keyword makes the file invisible to its own gate. Enforced by the meta-test now.
  - Native form controls get their `:focus-visible` ring from `primitives/form-focus-ring.ts`. The `outline` reset must stay in that CSS, never in an inline style — inline outranks the pseudo-class rule and silently kills the indicator.
  - `PekuloCalendar` passes `locale={fr}` from `react-day-picker/locale`. Any new date surface does the same; `{...props}` spreads last so consumers can still override.
- **Files:** `packages/ui/src/ds-coverage.meta.test.ts` (the gate) · 23 `*.snapshot.test.tsx` + 9 `*.a11y.test.tsx` across `components/` and `primitives/` · `primitives/form-focus-ring.ts` · sources touched at review: `PekuloInput`, `PekuloTextarea`, `PekuloNativeSelect`, `PekuloCalendar`, `PekuloDatePicker`, `PekuloEmpty` · `toast/{snapshot,a11y}.test.tsx`.
- **Contracts:** `PEKULO_FIELD_CLASS` / `PEKULO_FIELD_CSS` exported from `primitives/form-focus-ring.ts` — the shared focus contract for native controls. `PekuloEmpty`'s `outlined` prop was **removed** (no consumer existed). `PekuloEmptyMedia`'s icon chip is now 48px / `radius-full`.

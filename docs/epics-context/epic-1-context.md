Lint rules `no-server-action-in-component`, `no-cross-feature-action-import`, `no-prisma-query-without-user-id` all gate this path (story 0-12 shipped them).

  - **RLS defense in depth (ADR-0013)** — every Prisma query carries explicit `where: { userId: ctx.userId, … }`; RLS stays active even if `apps/api` omits the guard. Story 0-12's `pekulo/no-prisma-query-without-user-id` rule blocks omissions in `apps/api/src/modules/**/*.repository.ts`.

  - **Decimal coercion (L24, 2026-05-04)** — Prisma `Decimal` columns must be coerced via `.toNumber()`, not `Number(decimal)`. Apply at the repository → service → DTO boundary (existing pattern in `hypothesis.service.ts#decimalToNumber`). Story 1-1 explicitly named in L24's scope list.

Forward-only. **The 4 RLS policies (audit variant: INSERT + SELECT only) are appended manually to the migration SQL — Prisma does not introspect policies.** `rls-audit` CI re-asserts coverage.

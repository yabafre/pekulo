## Lessons applicable

- **2026-05-04 (Scope: aped-arch, aped-story, aped-dev — explicitly lists story 6-1) — Elysia 1.4 `Elysia` type is invariant.** NEVER annotate a variable/param as bare `Elysia`. Module factories return INFERRED chains (drop `: Elysia` return annotations); cross-cutting boundaries use `AnyElysia`. Pre-impl check: `grep -rn ': Elysia\b' apps/api/src` should surface only already-constrained `(deps): Elysia<…>` shapes.
- **2026-05-20 (Scope: aped-arch, aped-dev, aped-review; "Apply to … 6-X (LLM categorisation)") — `defineAction` with discriminated-union envelope MUST omit `output:`.** zapaction core runs `output.parse(result)` unconditionally; a success-only schema rejects the `{ok:false}` branch at the SA boundary. Validate the success branch inside the try block if runtime validation is needed.
- **2026-05-19 (Scope: aped-story, aped-dev, aped-review) — `bun --filter='@pekulo/api'`, NOT `bun --filter=api`.** Every T-task command in the story uses the full quoted workspace name (`bun --filter='@pekulo/api' run …`). Reviewers reject the short form.
- **2026-05-17 (Scope: aped-story, aped-arch, aped-dev) — Story-spec UX placement MUST be cross-checked against `docs/ux-preview/src/App.tsx`** before pinning a CRUD surface / section placement. Relevant to downstream 6-3/6-4/6-5; 6-1 has no UI.
- **2026-05-05 (Scope: aped-dev, aped-story) — `bun --cwd <relative>` silently fails.** Use cd-then-run or `--filter`.
- **2026-05-05 (Scope: aped-dev, aped-story, aped-arch) — Prisma 7 `defineConfig` evaluates `env("DATABASE_URL")` at config-load time** even for no-connection commands — relevant to CI/Docker prisma format/validate.
- **2026-05-27 (Scope: all — find-or-create) — find-or-create over a UNIQUE-constrained key MUST catch P2002 + re-read.** If `LlmOptIn` is keyed `UNIQUE(user_id)` and the router lazily creates a default-`false` row, the create path needs the `try { create } catch (P2002) { re-read }` shape (mirrors `resolveProviderUserUuid` in 5-6).
- **2026-05-24 (Scope: aped-arch, aped-dev, aped-review) — `defineAction({ tags })` is server-only / dead without an RSC fetch-cache reader.** Downstream 6-3/6-4/6-5 hooks pass `invalidateWithTags` via `useActionMutation`; drop the SA-side `tags:` unless a real RSC `await fetch` reader exists.
- **2026-05-20 (Scope: aped-dev, aped-qa, aped-review) — Vitest `vi.mock` factory is HOISTED → use `vi.hoisted`** for envelope-narrowing error-path tests of any 6-X web action.

## Architecture references

- Patterns to respect:
  - **Test contract** (architecture.md:631) — "`@pekulo/ui` components: 1 visual snapshot + 1 vitest-axe a11y spec per public component." All 33 primitives are exported through `src/primitives/index.ts`, so the contract covers them, not just the 42 `Pekulo*` domain components.
  - **Test pyramid** (architecture.md:247, ADR-0002) — `@pekulo/ui` + `apps/web` run **vitest**; `apps/api` runs **bun test**. CI fans out through per-package `test` scripts (`bun --filter='*' run test`) — never short-circuit the workflow to a single runner (lesson 2026-05-07).
  - **R11 folder-by-domain** (architecture.md:776) — components follow `components/PekuloX/PekuloX.tsx` + co-located `PekuloX.a11y.test.tsx` / `PekuloX.snapshot.test.tsx` / `index.ts`. **Primitives are an exception in practice**: they are flat files in `src/primitives/`. Any coverage tooling must handle both shapes; normalising the primitives into R11 folders is a separate refactor, not epic-10 scope.
  - **`@pekulo/ui` is the sole styling surface** (architecture.md:552) — `tailwindcss` outside the package is forbidden, lint-enforced by `pekulo/no-tailwind-outside-ui`. Rule status **verified live 2026-08-16**: fires on `apps/web/src/`, silent on `packages/ui/src/`. Never infer a self-gating rule's activity from a green lint (lesson 2026-06-15).
  - **R7 barrel discipline** (architecture.md:748) — `provider/` must not import from `components/`. Snapshot files import the component directly (`./PekuloX`), never through the package barrel, so they cannot close a cycle.
  - **Snapshots encode Tamagui atomic classes** generated at runtime under `disableInjectCSS`. They are coupled to the Tamagui version, not to the committed `public/tamagui.generated.css` — that artefact has its own CI guard (`tamagui-css-fresh`).

  - **ADR-0002** — Test pyramid (Vitest + Playwright + axe + Lighthouse CI + pytest).

## Project context (brownfield only)

- Existing patterns the epic must respect:
  - **The suite already exists.** 52 snapshot files + 66 a11y files ship as of 2026-08-16. Epic 10 closes the remaining gap (23 snapshots, 2 a11y specs) and adds the gate that keeps it closed — it does not bootstrap the suite.
  - **Established test shape** — `renderWithTamagui` from `packages/ui/test/setup.tsx` + `toMatchInlineSnapshot`. 52/52 existing files are inline; there is no `__snapshots__/`-file pattern to follow. Import depth differs by location: `src/components/<Name>/` → `"../../../test/setup.tsx"`, `src/primitives/` → `"../../test/setup.tsx"`.
  - **`test/setup.tsx` forces `prefers-reduced-motion: reduce`** so rAF-driven count-ups and donut sweeps settle at their final frame. Snapshot stability depends on it; do not reassign `window.matchMedia` in a snapshot file.
  - **Filtered scripts key off test names** — `test:visual` is `vitest run --passWithNoTests --testNamePattern='snapshot'`, `test:axe` is the same with `'a11y'`. A spec whose `describe`/`it` title omits the keyword is invisible to its own gate.
  - **Portal primitives snapshot as the empty shell** (`PekuloDialog`, `PekuloSheet`, `PekuloPopover`, `PekuloTooltip`, and `PekuloDrawer`) — `"<span class=\"_dsp_contents  font_body\"><div style=\"display: contents;\"></div></span>"` is the correct capture for them, and a red flag for anything else.
  - **CI reality** — `.github/workflows/pr.yml` runs `lint`, `format-check`, `typecheck`, `test-unit`, `prisma-check`, `rls-audit`, `gitleaks`, `prices-tests`, `tamagui-css-fresh`. The `lighthouse-ci`, `axe-a11y` and `test-e2e-smoke` jobs were **removed 2026-05-24** to free Actions quota; axe coverage lives inside `test-unit` via the per-component `vitest-axe` specs. Re-adding a dedicated axe job is story 11-4's call, not this epic's.
  - **Workspace naming** — `bun --filter='@pekulo/ui'`, never `--filter=ui` (lesson 2026-05-19). Never `bun --cwd <relative>` — it exits 0 silently on a bad path (lesson 2026-05-05).

## Lessons applicable

- **2026-06-05 (aped-story/dev/review)** — a design-gate scope expansion into a NEW subsystem is split into sibling stories. In this epic that line falls between 10-1 (web baseline, one runner, tests only) and 10-2 (Expo app + Maestro — a genuine new subsystem, gated on G1).
- **2026-06-05, second half (aped-dev/review)** — the cheap class-killer meta-test: enumerate the source of truth and assert registration. Born from `ID_PREFIXES` shipping a model unregistered twice; the DS coverage gap is the same failure class and takes the same shape.
- **2026-06-15 (aped-dev/review)** — a custom oxlint rule that self-gates on `context.filename` can be silently INERT while lint is green. Prove activity with a committed deliberately-violating fixture, in both directions (fires outside the exempt root, silent inside it).
- **2026-05-17 (aped-story/arch/dev)** — cross-check any UX placement claim against `docs/ux-preview/src/App.tsx` before implementing; the rendered design outranks `screen-inventory.md` and story prose.
- **2026-05-17 (aped-dev)** — `PekuloMobileBottomNav`'s five equal cells are CSS Grid `repeat(5, 1fr)`, not flex `flex: 1`. Flex distributes leftover space and truncates the 12-char labels at 390 px.
- **2026-05-20 (aped-dev/review/qa)** — `vi.mock` factories are hoisted; a mock referenced from a factory must come from `vi.hoisted(() => ({ … }))`.
- **2026-05-20 (aped-dev/qa)** — form-submit assertions use `fireEvent.submit(getByRole("form", { name }))`; `fireEvent.click` on a submit button does not reliably fire `onSubmit` under happy-dom.
- **2026-05-07 (aped-dev/review)** — `bun test` ≠ `vitest run`. CI must invoke per-package `test` scripts; `@pekulo/ui` cannot drop vitest without losing the `vitest-axe` harness.
- **2026-05-06 (aped-dev/qa)** — Tamagui compound triggers (`Popover`, `Tooltip`, `Select`) must `render="button"` or axe flags `aria-allowed-attr` as critical. Any new a11y spec on a compound primitive checks this first.
- **2026-05-07 (aped-dev/review)** — `$accent` (emerald) is reserved for ± monetary deltas; control chrome is grayscale. A snapshot freezing the wrong token freezes the violation.
- **2026-06-01 (aped-dev)** — pre-commit hooks do NOT run `tsc`; treat `bun --filter='@pekulo/ui' run typecheck` as a mandatory manual gate before every commit.
- **2026-05-24 (aped-dev/review)** — new `styled(...)` / variants / theme tokens require `bun run generate:tamagui-css` or they never reach the DOM. A green build is not proof the style shipped.
- **2026-05-31 (aped-story/dev/review)** — features added after the step-04 scope lock desync the docs; any mid-flight addition carries its own doc-sync (ADR + epics + architecture + ticket) in the same change.

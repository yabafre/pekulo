## Project context (brownfield only)

Existing patterns the epic must respect:

- Domain-by-feature: each domain has parallel files in the apps/api module + a web `*-actions.ts` thin `'use server'` wrapper + feature keys/tags in `zapaction/keys.ts`.
- Reads go through `data/` (web) → oRPC client → `apps/api` module read path; writes through `actions/`. Server-only modules start with `import "server-only"`.
- RLS per-row `auth.uid() = user_id` on every user-data table; `apps/api` service-role connection bypasses RLS but every query is user-id-scoped (oxlint `no-prisma-query-without-user-id`).
- Graceful degradation in readers (return safe fallbacks); FX best-effort falls back 1:1 inside `derive-portfolio-fx` (architecture / project-context L75, L100). The total-wealth aggregator must not throw when one source is empty — it sums what exists.
- `bun --filter` targets the **package name** `@pekulo/<pkg>`, not the folder (lesson 2026-05-19).

## Lessons applicable

- **Coerce Prisma `Decimal` via `.toNumber()`** at every Prisma→DTO boundary — `Number(decimal)` silently truncates above MAX_SAFE_INTEGER (2026-05-04; scope lists stories 7-1, 7-3). Binds every term of `computeTotalWealth`.
- **Elysia 1.4 `Elysia` type is invariant** — use type inference + `AnyElysia` at module boundaries, never annotate the concrete `Elysia` generic (2026-05-04; scope lists 7-1, 7-3).
- **Registry-SSOT cache invalidation, no wall-clock promises** — every mutation hook declares `invalidateWithTags: [<feature>Tags.X()]`; optimistic `onMutate` is opt-in, not the default. Manual `queryClient.invalidateQueries` in a hook body is a review fail (R4). FR-44's "dashboard refetches via the invalidation tag" is met by the registry edges, not a manual call (2026-05-25; R4 L727-731).
- **`tsc` is NOT in the commit gate** — run `bun --filter=@pekulo/<pkg> run typecheck` (+ relevant `bun test`) before every commit; after any Prisma schema change, `prisma:generate && typecheck` is one inseparable step (2026-06-01).
- **Mid-flight scope additions carry doc-debt paid in the same change** — if 7-x grows past its step-04 scope lock, supersede (don't delete) the scope note, record the realized decision in the owning ADR Consequences, refresh the architecture driver line, write the lesson (2026-05-31; scope: aped-story/dev/review).
- **Cross-check any UI placement against `docs/ux-preview/src/App.tsx`** before implementing (2026-05-17) — relevant to 7-2 / 7-4.
- **New cap-view routes land under `(cap)/dashboard/<feature>/`**, never `(cap)/` directly, or they render without the CapShell (2026-05-27) — relevant to 7-2 / 7-4.
